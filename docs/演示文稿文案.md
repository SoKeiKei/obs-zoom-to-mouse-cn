## 幻灯片 11：核心功能 · 键盘输入检测

**标题：** 输入保护 · 不打断思路

**内容：**

**功能说明：**
检测用户正在输入文字或操作滚轮时，禁用自动缩小

**检测范围：**
- 键盘按键（字母、数字、功能键）
- 鼠标滚轮（上/下滚动）

**可配置参数：**
| 参数 | 范围 | 默认值 |
|------|------|--------|
| 输入暂停延迟 | 1-30 秒 | 2 秒 |

**工作流程：**
```
检测到输入
  → 重置计时器
  → 保持放大状态
  → 停止输入 2 秒后恢复检测
```

**适用场景：**
- 代码演示时输入命令
- 文档编辑时打字
- 网页浏览时滚动

## 幻灯片 12：核心功能 · 二级缩放

**标题：** 双级缩放 · 更精细的控制

**内容：**

**功能说明：**
独立的二级缩放级别，支持三级状态切换

**缩放级别：**
1. 原始状态（1x）
2. 二级缩放（如 1.5x）
3. 最大缩放（如 2x）

**热键操作逻辑：**
```
第 1 次按下：1x → 1.5x（二级缩放）
第 2 次按下：1.5x → 2x（最大缩放）
第 3 次按下：2x → 1.5x（返回二级）
第 4 次按下：1.5x → 1x（退出缩放）
```

**独立控制：**
- 与主缩放热键互不干扰
- 可配置二级缩放倍数（1.1x - 最大倍数）

## 幻灯片 19：常见问题解答

**标题：** FAQ 常见问题

**内容：**

**Q1: 为什么缩放源列表为空？**
A: 确保场景中已添加显示器捕获源，点击「刷新缩放源」按钮

**Q2: 缩放位置不准确怎么办？**
A: 启用「设置手动源位置」选项，手动配置显示器位置

**Q3: 如何在非显示器捕获源上使用？**
A: 启用「允许任意缩放源」选项，必须设置手动源位置

**Q4: 自动缩小不触发？**
A: 检查是否开启了输入检测，或调整静止延迟时间

**Q5: 跟随鼠标有延迟？**
A: 调高跟随速度和平滑系数，启用平滑跟随

**Q6: 键盘检测无效？**
A: 目前仅支持 Windows 平台

## 设计说明

### 整体风格
- **配色方案：** 深色主题（#1a1a2e 背景）
- **主色调：** OBS 蓝（#3498db）+ 强调橙（#e74c3c）
- **字体：** 思源黑体 / Noto Sans SC
- **图标风格：** 扁平化线性图标

### 动画效果
- 页面切换：淡入淡出 + 轻微缩放
- 内容出现：从下往上滑动
- 强调元素：轻微脉动动画
- 图表：线条绘制动画

### 交互设计
- 可点击目录跳转
- 代码块可复制
- 截图可放大查看
- 响应式布局
