# OBS 鼠标缩放 (中文威力加强版)

一个功能强大的 OBS Studio Lua 脚本，用于将显示器捕获源缩放到鼠标位置，支持自动跟随、智能缩放和键盘输入检测。

## 功能特性

### 核心功能
- 将显示器捕获源缩放到鼠标位置
- 自定义缩放倍数（1x - 5x）
- 可调节缩放动画速度
- 自动跟随鼠标移动
- 支持多显示器配置
- 支持远程鼠标位置监听（UDP套接字）

### 二级缩放系统（v2.2 新增）
- 独立的二级缩放倍数配置（1.1x - 最大倍数）
- 支持三级缩放状态切换（原始 → 二级 → 最大）
- 独立热键控制，与主缩放互不干扰
- 适合看代码细节用二级，看局部用最大

### 丝滑移动与缩放算法（v2.2 新增）
- 速度预测算法：提前预判鼠标移动趋势
- 缓动函数优化：起步柔和，收尾自然
- 动态回弹修正：自动校正微小偏移
- 缩放中持续跟随：减少动画结束后的跳变感
- 平滑系数可调：0.16 默认值，平衡灵敏与稳定

### 智能自动化（v2.0 新增）
- 鼠标静止自动缩小（可配置延迟 1-30 秒）
- 鼠标移动自动恢复缩放
- 键盘/滚轮输入检测（输入时不触发自动缩小）
- OBS 启动时自动缩放（无需手动激活）

### 高级参数（v2.2 新增）
- 缩放丝滑度：使用更柔和的缓动曲线，接近 Screen Studio 风格
- 跟随回弹强度：控制跟随时的预判量，越大越有提前量
- 回弹最大像素：限制预判位移上限，避免快速甩动时回弹过大

### 中文界面（v2.0 新增）
- 完整的中文界面支持
- 中文帮助文档和提示信息
- 动态宽高比适配（竖屏直播/超宽屏幕完美支持）

## 安装方法

1. 下载 `obs-zoom-to-mouse-cn.lua` 文件
2. 打开 OBS Studio
3. 菜单栏选择 **工具** → **脚本**
4. 点击 **+** 按钮添加脚本
5. 选择下载的 `obs-zoom-to-mouse-cn.lua` 文件

## 使用说明

### 基本设置

| 设置项 | 说明 |
|--------|------|
| 缩放源 | 选择要缩放的显示器捕获源 |
| 缩放倍数 | 缩放的程度（1-5倍），默认2倍 |
| 启用二级缩放 | 开启二级缩放系统（中间档位） |
| 二级缩放倍数 | 二级缩放中间级别（1.1-缩放倍数），默认1.5倍 |
| 缩放速度 | 缩放/缩小动画的速度 |
| 缩放丝滑度 | 使用更柔和的缓动曲线，让缩放更接近 Screen Studio 风格 |
| OBS启动时自动缩放 | OBS启动时源已缩放 |
| 动态宽高比 | 根据画布源大小调整缩放宽高比 |

### 跟随设置

| 设置项 | 说明 |
|--------|------|
| 自动跟随鼠标 | 缩放时跟踪光标 |
| 边界外跟随 | 即使光标在源边界外也跟踪光标 |
| 跟随速度 | 缩放区域跟踪鼠标的速度（0.001-1，支持更低速档位） |
| 跟随边界 | 从源边缘重新启用鼠标跟踪的距离百分比 |
| 锁定灵敏度 | 跟踪需要多接近才会锁定位置 |
| 反向自动锁定 | 如果反转鼠标方向则自动停止跟踪 |
| 平滑跟随 | 使用速度预测和缓动函数使跟随更丝滑 |
| 平滑系数 | 控制平滑程度（值越小越平滑，值越大越灵敏） |
| 跟随回弹强度 | 控制跟随时的预判量（越大越有提前量） |
| 回弹最大像素 | 限制预判位移上限，避免快速甩动鼠标时回弹过大 |

当前版本已内置一组更偏录屏演示风格的跟随默认值：
- 小幅移动更稳，减少微抖
- 缩放过程中持续跟鼠标，减少动画结束后的跳变感
- 回弹强度和回弹最大像素可按个人习惯调整


### 自动缩小设置

| 设置项 | 说明 | 默认值 |
|--------|------|--------|
| 鼠标静止自动缩小 | 当鼠标静止超过指定时间后自动缩小回原始倍率 | 关闭 |
| 静止延迟(秒) | 鼠标静止多长时间后自动缩小 | 3秒 |
| 检测键盘输入 | 检测到键盘/滚轮输入时不会自动缩小 | 关闭 |
| 输入暂停延迟(秒) | 停止输入后多长时间才允许自动缩小 | 2秒 |

### 热键

脚本提供四个可自定义的热键：

1. **切换鼠标缩放** - 开启/关闭缩放功能（直接切换到最大倍数）
2. **切换二级缩放** - 从原始状态进入二级缩放，并在二级缩放与最大缩放之间独立切换
3. **切换缩放时跟随鼠标** - 开启/关闭鼠标跟随
4. **切换鼠标静止自动缩小** - 开启/关闭自动缩小功能

在 OBS 设置 → 热键 中可以自定义这些快捷键。

**二级缩放功能说明：**
- 首次按下：从原始状态缩放到二级缩放倍数（如1.5x）
- 再次按下：从二级缩放继续放大到最大倍数（如2x）
- 后续按下：在二级缩放与最大倍数之间来回切换
- 回到原始比例：使用主缩放热键退出缩放
- 与"切换鼠标缩放"热键互不影响

## 注意事项

1. **显示器捕获源**：此脚本主要针对显示器捕获源优化，使用其他类型的源需要手动配置位置信息
2. **多显示器**：如果使用多显示器，确保选择正确的显示器捕获源
3. **性能影响**：高频率的鼠标跟踪可能对性能有一定影响，建议根据需要调整跟随速度
4. **键盘检测**：目前键盘检测功能仅支持 Windows 平台

## 常见问题

### Q: 为什么缩放源列表为空？
A: 确保场景中已添加显示器捕获源，然后点击"刷新缩放源"按钮。

### Q: 缩放位置不准确怎么办？
A: 尝试启用"设置手动源位置"选项，手动配置显示器的位置和大小信息。

### Q: 如何在非显示器捕获源上使用？
A: 启用"允许任意缩放源"选项，然后必须设置手动源位置参数。
